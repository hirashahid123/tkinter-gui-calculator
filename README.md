# Simple Calculator

A basic calculator GUI built with Python's Tkinter library.

## Features
- Number pad and basic operators (+, -, *, /)
- Clear button to reset input
- Simple, clean interface

## Known limitations
- Dividing by zero shows "Error"

## How to run
1. Make sure you have Python installed
2. Run the script

## Built with
- Python
- Tkinter (standard GUI library)
